One invented word for make.fun's "Invent a Word We Need" bounty: **savepile** — the growing pile of posts and videos you saved for later and will never open again. Everyone has one: the bookmark folder, the watch-later list, the saved posts nobody ever reopens.

`main.py` (Python 3.13, standard library only) writes the word and its one-line definition to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader's container). Deterministic: every run writes exactly the same 99 characters, one line, no trailing newline.

## Run it

```sh
python3 main.py
```
